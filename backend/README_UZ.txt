1) .env.example faylidan nusxa olib .env qiling.
2) .env ichiga BOT_TOKEN va ADMIN_CHAT_IDS ni yozing.
3) Terminalda shu papkani oching.
4) Buyruqlar:
   python -m pip install -r requirements.txt
   python app.py
5) Sayt: http://127.0.0.1:5000
6) Admin sahifa: http://127.0.0.1:5000/admin
7) Telegram botda /start yuboring.
8) Bot sizga "Excel formatda ko'rish" tugmasini chiqaradi.
9) Saytdan yuborilgan har bir ma'lumot Excelga saqlanadi va Telegram admin chatga xabar boradi.
10) SEND_EXCEL_TO_ADMIN_EACH_SUBMISSION=true bo'lsa, har yangi anketa kelganda Excel fayl ham Telegramga yuboriladi.
